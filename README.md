# Sistem Pencatatan Hasil Panen Digital

## Deskripsi Singkat
Program Python sederhana ini digunakan untuk menghitung total pendapatan hasil panen pertanian serta kalkulasi potongan harga (diskon) secara otomatis. Proyek ini dibuat sebagai latihan manajemen versi kode menggunakan Git dan GitHub.
